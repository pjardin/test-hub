Credentials for tests that have to log in

Test files travel — laptop, zip, disc, git. A password written into one travels with it. So credentials live only on this machine in a 0600 file, and a test refers to them by name: ctx.secret("target_password"). Move the test anywhere and it works as soon as that machine has its own value for the name — which is also right, because the lab password should not be the laptop password.

Values are never shown again after saving, never included in a backup or a tests export, and are redacted from run logs, error messages and results even if a test prints one by accident.
